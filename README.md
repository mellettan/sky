# Звёздное небо в терминале

Простой аналог Stellarium на символах Брайля с 24-битным цветом. Нужен терминал с truecolor и мышью (kitty, alacritty, wezterm, gnome-terminal).

## Запуск

```
./sky
```

Если `data/` нет, сначала скачать каталог звёзд (HYG, ~115 тыс. звёзд) и орбиты комет (JPL):

```
python3 -m venv .venv && .venv/bin/pip install numpy
.venv/bin/python fetch_data.py
```

Добавить свою комету — дописать её обозначение в список `COMETS` в `fetch_data.py` и выполнить `.venv/bin/python fetch_data.py comets`.

## Управление

| Клавиша | Действие |
|---|---|
| мышь: тянуть / колесо | повернуть взгляд / зум к курсору |
| мышь: навести / клик | подпись объекта / выбрать объект |
| стрелки (Shift — быстрее) | повернуть взгляд |
| `+` `-` `z` | зум, сброс зума |
| `g` | ландшафт вкл/выкл |
| `a` | атмосфера вкл/выкл |
| `l` | подписи вкл/выкл: Солнце, Луна, планеты, кометы и яркие звёзды; при зуме подписываются всё более слабые звёзды |
| `[` `]`, `1`…`9`, клик по ползунку | засветка по шкале Бортля |
| пробел | пауза |
| `,` `.` | медленнее / быстрее, в том числе назад во времени |
| `<` `>` | час назад / вперёд |
| `PgUp` `PgDn` | сутки назад / вперёд |
| `n` | текущий момент |
| `t` | дата и время (`1997-04-01 21:30`, `01.04.1997`, `21:30`) |
| `c` | координаты (`55.75 37.62`, `33.9S 151.2E`) или город |
| `/` | поиск: планеты, Луна, Солнце, кометы, звёзды по имени |
| `f` | следить за выбранным объектом |
| `?` | справка, `q` — выход |

Время везде показывается и вводится в часовом поясе компьютера, даже если выбран другой город. Место, засветка и переключатели (ландшафт, атмосфера, подписи) сохраняются в `config.json`.

## Живые обои

```
./wallpaper
```

Запускает небо на слое обоев через `kitty +kitten panel --edge=background` (Wayland с wlr-layer-shell: Hyprland, sway). Вид задаётся в самом скрипте `wallpaper` аргументами `sky.py`: `--az 205 --alt 0 --fov 120 --bortle 7`; можно также `--horizon 0.33` (на какой доле высоты экрана от низа стоит центр взгляда; при `--alt 0` горизонт идёт там ровной линией), `--place "сидней"`, `--interval 10`, `--no-labels`, `--no-landscape`, а крупность точек — через `font_size` в скрипте. Место по умолчанию берётся из `config.json`, сам режим обоев ничего в него не пишет. Повторный запуск `./wallpaper` перезапускает обои, остановить — `pkill -f class=sky-wallpaper`.

## Что интересного посмотреть

- `t` → `1997-04-01 21:30`, `/` → `хейла`: комета Хейла — Боппа с двумя хвостами.
- `c` → `сидней`, `t` → `1986-04-09 20:00`, `/` → `галлея`: комета Галлея (20:00 по Москве — это 3 часа ночи в Сиднее).
- `/` → `сатурн` и сильный зум колесом: кольца (в 2026 почти ребром), у Юпитера видны полосы.
- `/` → `луна` и зум: фаза и моря.
- `1` и ночь без Луны: Млечный Путь.
- `t` → `1887-08-19 07:10`, `/` → `солнце`, зум колесом: последнее полное солнечное затмение в Москве (полная фаза 07:15–07:17). Следующее — `2126-10-16 11:30`.
